# Backups

O servidor da loja faz cópia do banco de dados todos os dias. Em **Configurações → Sistema** você vê:

- quando foi o último backup e se deu certo;
- alertas abertos (por exemplo, disco quase cheio ou backup atrasado);
- quem recebe os alertas por e-mail ou notificação.

Se um alerta aparecer, não ignore: um backup que falha em silêncio só é descoberto quando você precisa dele. Peça ajuda ao suporte.

Para restaurar um backup, fale com o suporte: a restauração substitui os dados atuais e precisa ser feita com cuidado.
