# WhatsApp

Em **Configurações → WhatsApp** você liga o número da loja à API oficial do WhatsApp (Meta). Com isso:

- o cliente recebe mensagens quando o pedido é confirmado, fica pronto e sai para entrega;
- o cliente pode pedir pelo próprio WhatsApp, com um link para o cardápio;
- campanhas e cupons podem ser enviados para quem aceitou receber.

Só recebe mensagens de promoção quem marcou que aceita. Mensagens sobre o pedido vão para quem pediu avisos no checkout.

A Meta cobra por conversa. Os valores ficam na sua conta Meta, não aqui.
